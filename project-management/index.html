PowerPoint Export Instructions

  1. Open PowerPoint > Alt + F11 > Ctrl + M
  2. Locate and select the downloaded Gantt_Roadmap .bas file.
  3. Once imported, you will see a new folder named Modules appear in the left sidebar, containing GanttExporter. You can now close the VBA window by clicking the X in the top right.
  4. Press Alt + F8 on your keyboard to open the Macro dialog box.
  5. Select GenerateGanttTimeline and run.
Planner runs locally in your browser. GitHub sync writes to the repository only when you click Save.
